GVA Scenario Modeler - Basic Usage

Quick guide to modeling employment, profit, and GVA scenarios.

1. Initializing Baseline Figures

Set initial Turnover, Net Profit, Employee Count, and Salary Costs. Click the Edit Baseline button in the summary panel to modify these values at any point.

2. Scenario 1 (Without Grant)

Simulates growth path without grant intervention. Adjust forecasted Turnover by dragging points on the SVG chart, set annual headcount forecasts, and use sliders to set target net profit margins.

3. Scenario 2 (With Grant)

Simulates project-supported growth. Headcount forecasts are driven by detailed **Salary Bands** of new jobs created. You can also log Upskilled FTEs and custom training notes.

4. GVA & ROI Calculations

Gross Value Added (GVA) is calculated as: Employee Costs + Net Profit. Incremental GVA is the difference between Scenario 2 and Scenario 1. Set the intervention cost in Project cost (£k) to evaluate the Return on Investment (ROI) multiplier.

5. Comparison & Sanity Checks

Click Expand in the Comparison Metrics panel to view sanity check warnings. This checks average salaries (caution if below £12k or above £150k), baseline alignment, profit margin boundaries (0% to 50%), and GVA ROI health.
